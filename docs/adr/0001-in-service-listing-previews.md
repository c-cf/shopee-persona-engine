# 在服務內交付模擬商品頁

原始 roadmap 透過 Copy Prompt 與外部 Listing Skill 生成內容，再操作 Shopee Seller 表單；2026-09-12 的設計訪談決定，第一版在本服務內生成標題與文案，並以五至十個模擬 Shopee 商品頁供既有賣家比較。使用者的完成點是看到候選頁面的呈現，不包含實際上架，因此外部 Agent、Skill 安裝及 Seller 填表不構成主流程的前置條件。服務需要負責內容生成與預覽；實際 Shopee 發布整合不在第一版範圍，Skill 進階匯出的具體需求留待後續確認。
