# 第一版介面方向

以賣家的商品工作台為主體，主色使用 Shopee 橘 #ee4d2d，搭配紙白 #ffffff、冷灰 #f3f5f7、墨藍 #23313a、青綠 #258b79 與淡紫 #8b68b5。中文字使用系統繁中文字型，英數使用 Arial，標題 28–36px、內文 14–16px。

上方為品牌、專案回訪與流程步驟；帶入商品採左方輸入、右方示範商品；分析階段以三組受眾提供可選方向；預覽階段則以左方版本清單、中間商品頁、右方受眾及編輯工具構成工作區。手機收斂為單欄。

辨識重點放在可操作的模擬商品頁與原商品插畫。捨棄大型行銷首頁、裝飾性統計與無意義分數；產品內容與受眾情境承擔視覺重點。示範受眾與樣板文案清楚標示，與真實評論分析區分。
