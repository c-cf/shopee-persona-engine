# Diagrams / 流程圖

[Docs](../../README.md) · [Brand assets](../brand/README.md)

These bilingual diagrams illustrate the pitch's research workflow:
review needs → persona registry → product pairing → exploration scores → listing previews.
They describe the research method, not a complete map of the checked-in runtime.
See [methodology](../../methodology.md) for scope and [architecture](../../architecture.md)
for the repository implementation.

雙語流程圖對應簡報研究方法：評論需求 → 人物樣態集合 → 商品配對 → 探索評分 → 商品頁預覽。此圖不是 repo 已實作功能的完整架構；研究範圍及現行實作分別見方法與架構指南。
