# Brand assets / 品牌資產

[Docs](../../README.md) · [Project homepage](../../../README.md)

The identity centers on **a buyer outside the frame**. An open frame sets the
expected picture; a person extends beyond its edge. The symbol expresses the
project's question, “Who else needs it?”, without relying on a letter monogram.

品牌以「框外的人」為核心：開放框線代表原先看見的範圍，人物跨出邊界，呼應找到原本沒想到的買家。

The README hero uses an orange editorial panel, oversized type and a schematic
Smart Plug → aquarium-lighting scene. It follows the pitch's lead example. The
illustration is conceptual, not product photography or a scheduling interface.
The app header and favicon use the same mark; this source change does not update
the separately hosted deployment.

首頁採橘色海報版面、大字標題，以及「智慧插座 → 魚缸照明」概念圖，與簡報主案例一致。圖像不是商品實拍或排程操作介面。Repo 的產品頁首及 favicon 同步使用新標誌；此原始碼修改不會直接更新另行部署的網站。

## Palette / 色彩

| Color | Value | Role / 用途 |
| --- | --- | --- |
| Discovery orange | `#FF683F` | Hero panel and accent／主視覺與重點色 |
| Ink | `#172126` | Type and structure／文字與線條 |
| Paper | `#F7F4EB` | Illustration background／插畫底色 |
| Aquarium teal | `#147E78` | Context illustration accents／情境輔助色 |

SVGs contain editable vector paths and text, with no external resources or scripts.
Hero backgrounds preserve contrast in GitHub light and dark themes. Use the light
logo on dark backgrounds and keep clear space around the symbol. These are original
project graphics, not Shopee's official logo or an endorsement mark.

SVG 保留可編輯圖形及文字，沒有外部資源或腳本。Hero 的實色底適合 GitHub 明暗主題；深色背景使用淺色標誌，保留標誌周圍留白。圖形為專案原創，不是 Shopee 官方商標或背書標章。

English display type uses Arial Black with Arial/Helvetica fallbacks; Traditional
Chinese uses PingFang TC with system fallbacks. The project license is unspecified;
these assets do not carry a separately assigned reuse license.

英文大標使用 Arial Black，繁中使用 PingFang TC，皆設有系統替代字型。專案授權尚未指定，資產未另訂重用授權。
